# OCDyssey website



## Included files
- `index.html` - main website page
- `styles.css` - visual design and responsive layout
- `script.js` - mobile navigation, donation amount selector, and contact form mailto behavior
- `assets/logo-full-web.png` - full OCDyssey logo used in the hero section
- `assets/logo-mark-web.png` - logo mark used in the header and footer
- `assets/favicon.png` - browser icon

## Updated details
- Contact email: `ocdyssey@gmail.com`
- Donation page: `https://zeffy.com/en-US/donation-form/ocdyssey`
- Brand direction: pastel yellows and blues

## What this version does
- Uses the real OCDyssey logo provided in chat
- Links the donate buttons to Zeffy
- Uses `mailto:` links and a simple contact form that opens the visitor's email app
- Works as a static website with no build step or backend required

## Publish options
You can upload this folder to:
- Netlify
- Vercel
- GitHub Pages
- Any standard web host that serves static files

## Notes
- Donation processing happens on Zeffy, not on the website itself.
- The contact form opens an email draft instead of sending through a server.
- You can later replace the email form with Google Forms, Tally, Jotform, Typeform, or a custom backend.
