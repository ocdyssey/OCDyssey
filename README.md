# OCDyssey website

This package contains the updated OCDyssey fundraising homepage.

## Included files
- `index.html` - standalone homepage with the logo, styles, and scripts embedded so it can work by itself on GitHub Pages
- `styles.css` - separate stylesheet copy
- `script.js` - separate script copy
- `assets/` - logo and favicon image files

## Updated details
- Contact email: `ocdyssey@gmail.com`
- Donation page: `https://zeffy.com/en-US/donation-form/ocdyssey`
- Organization status: `501(c)(3) nonprofit`
- Brand direction: pastel yellows and blues with a compassion-centered message

## What changed in this version
- Replaced the "Pastel blue + yellow brand" label with `Compassion-Centered`
- Restored the logo in the top-left header
- Embedded the logo, CSS, and JavaScript directly into `index.html` so the page is less likely to break on GitHub Pages

## GitHub Pages note
For the simplest setup, upload the standalone `index.html` to the root of your repository. Because the file is self-contained, it will still display correctly even if you have not uploaded the `assets` folder yet.

## Notes
- Donation processing happens on Zeffy, not on the website itself.
- The contact form opens an email draft instead of sending through a server.
